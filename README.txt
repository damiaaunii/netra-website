NETRA Public Product Website
============================

Project name: NTAMS — Network Traffic Analysis and Monitoring System
Public product / website name: NETRA
Tagline: See Beyond Traffic.

Files:
- index.html
- style.css
- script.js
- assets/netra-logo-dark.jpg
- assets/netra-logo-light.jpg

How to run:
1. Copy the whole folder into C:\xampp\htdocs\
2. Start Apache in XAMPP.
3. Open http://localhost/netra-public-site-v2/

Notes:
- The dashboard preview is intentionally a visual demo with sample values.
- The contact form is front-end only. Connect it to PHP/email later if required.
- Replace the placeholder contact numbers with your real team contact details.
- Dark/light mode is saved in the browser using localStorage.
